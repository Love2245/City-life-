```
├── src/
│   ├── game/
│   │   ├── core/        # 纯逻辑层：engine / time / actions / jobs / events /
│   │   │                #   contacts / survival / economy / equipment /

│   │   ├── data/        # 18 个 json 配置：actions / jobs / events / items /
│   │   │                #   regions / endings / housing / projects ...
```

> `node_modules/`、`dist*/` 已剔除，需先安装依赖。

## 常用命令

```bash
npm install              # 首次安装依赖

npm run dev              # 开发服务器（浏览器调试）
npm test                 # 跑全量单元测试

npm run tauri build      # 打包 Windows 桌面程序
```

## 已知注意事项

- 购买类行动（`buy_item`）必须调用 `applyItem`（写 `flags[item_*]` + 应用 `item.effects`），
  **不能**用 `equipItem`——后者只对带 `slot` 的装备生效，无 slot 物品会提前 return。
- 技能索引类型是 `SkillKey`（`keyof Skills`），不存在 `SkillId`。
- `vite build` 不要复用已存在的 `outDir`，用 `--outDir <新目录>` 避免删除超时。
