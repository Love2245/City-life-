✅ **已完成**

- **体力惩罚机制**（v0.91）：体力 <20 提示休息；归 0 后强行锻炼/工作/打游戏 → 晕倒（按余额 20% 收医药费、强制回家、恢复一半体力、时间跳 12 小时）

- **三级地图导航**：L1 主地图（市区/郊区🔒）→ L2 五大区域（中心/商场/工业/住宅/火车站🔒）→ L3 区域地点；面包屑导航 + 返回按钮
- **常驻任务栏**（v0.86）：右侧 240px 固定面板，展示当天全部任务（岗位 / 地点 / 打卡时刻 / 倒计时 / 报酬）；1 小时内变黄提醒、迟到红色脉冲；可一键收起为 44px 窄条（v0.89 修复收起后无法点开 Bug）

- **洗浴中心三档**（v0.86）：快速淋浴 30 元/1h（干净度 +45）· 泡澡按摩 120 元/3h（干净度 +80、体力 +15、压力 -8）· 全天套餐 300 元/24h（干净度饱食体力全回满）

## 启动

```bash
# 前端 dev（Vite）
pnpm dev

# 桌面端（需图形界面）
pnpm tauri dev

# 测试
pnpm test

# 类型检查
npx svelte-check

# 生产构建 / 便携版单文件
pnpm build
pnpm build:portable
```

## 目录结构

```
/workspace
├── src/
│   ├── game/              # ★ 纯逻辑层（禁 DOM/Svelte/Tauri import）
│   │   ├── types.ts       # 全部类型
│   │   ├── rng.ts         # mulberry32 可播种 PRNG
│   │   ├── engine.ts      # 门面：applyEffects/advanceTime/pushLog
│   │   ├── core/
│   │   │   ├── state.ts   # createInitialState
│   │   │   ├── time.ts    # 24小时制 / 睡眠结算 / 月结 / 饱腹衰减
│   │   │   ├── actions.ts # 行动加载 / 校验 / 结算 / 地图移动
│   │   │   ├── jobs.ts    # 日结劳务 / 固定岗位 / 浮动工资 / 到岗打卡
│   │   │   ├── quests.ts  # 任务系统（当日排班 / 迟到罚则 / 跨天归档）
│   │   │   ├── career.ts  # 正式工在职状态 / 周期发薪 / 自动离职
│   │   │   ├── statuses.ts# Debuff 调和（疲惫/劳损/饥饿等）
│   │   │   ├── events.ts  # 随机事件 / gamble
│   │   │   ├── housing.ts # 住宿三态 / 签约
│   │   │   ├── families.ts# 家庭条件 / 属性分配
│   │   │   ├── phone.ts   # 手机纯逻辑（电话/游戏/学习）
│   │   │   └── migrate.ts # 存档版本迁移链
│   │   └── data/          # JSON 数据（locations/actions/jobs/events/...）
│   ├── stores/            # Svelte 5 runes 状态管理
│   ├── views/             # 顶层视图
│   ├── components/        # 布局组件（CityMapView/PhoneView/各弹窗）
│   ├── lib/               # 前端工具（audio 音效/图标/格式化/存档）
│   └── styles/            # 主题 CSS
├── src-tauri/             # Rust 桌面壳
└── tests/                 # Vitest 单元测试
```
