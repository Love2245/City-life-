# 都市生活 v0.981

桌面端都市模拟游戏（灵感来自《属性与生活》）。单文件 HTML，双击即用。

## 运行方式
双击 `启动游戏_v0.981.bat`，或直接在浏览器打开 `都市生活_v0.981.html`。

## v0.981 更新内容

### 1. 移动端 UI 全面适配
- 修正 v0.98 失效的响应式断点（旧断点选择器拼错，导致除缩放外整块移动端布局从未生效）。
- 新增底部导航栏：场景 / 属性 / 任务 / 日志 一键切换，标签栏 54px 高并适配底部安全区。
- 弹窗全宽自适应（92vw、可滚动、关闭键与按钮统一 ≥44px 触控友好）。
- 根容器改用 `100dvh` 规避移动端地址栏高度跳变，并加 `viewport-fit=cover` 适配刘海屏安全区。
- 桌面端三栏布局完全不回归。

### 2. 郊区设施对齐市区
- 农村日结岗（农场 / 牧场 / 果园）接入工作小游戏与负责人点评。
- 游乐场 / 环湖公园 / 教堂 / 寺庙补齐参观效果与专属事件。
- 修复郊区行动三处契约违规：耗时字段 `hours`→`duration`、采购行动 `items`→`buy_item`、补齐 13 个郊区行动评价文案。

### 3. 市区 ↔ 郊区交通系统
- 无载具：坐长途巴士 20 元 / 2 小时。
- 电动车 / 三轮车：自行往返 1 小时 / 次（免费）。
- 汽车：0.5 小时 / 次（免费，自动优先）。
- 同一级区内跨子区维持既有地铁费率。

### 4. 宗教扩展
- 教会：每日 **告解**（缓解压力）；每周六 15:00–18:00 **弥撒**（提升心情，结束后必触发教友团建免费丰盛晚宴，大幅回饱）。
- 寺庙：义工后解锁 **素斋** 与 **禅房住宿**。
- 教堂 / 寺庙均支持 **24 小时祭拜**（每日限一次，缓解压力）。
- 教堂线与寺庙线互斥：受洗后寺庙关闭，寺庙圆满后教堂关闭。

### 5. 事件评价与文案优化
- 事件结算新增「后来怎么样了」结果文案（`outcome`）。
- 行动结算窗展示 S/A/B/C/D 评级与负责人点评。
- 新增统一收尾标语文案表；修复摆摊创业小游戏死键与负责人对话随机种子不一致。
