# v1.46 地图背景素材记录

本目录只记录本轮真正补齐或重绘的地图素材。运行时优先读取这里的资源；尚未需要重做的区域继续使用 `src/assets/bg/v1.43/atlas/{mapId}` 中已有的同构图、同天气、同时段 WebP，不把白天图冒充夜景。

## 商场外部 `downtown_mall`

这组图以一级地图中的商场区域为构图依据：商场主体占据画面中心，外街只保留便利店、电子城、快餐厅、健身房和商场入口；服装店、名牌店、家居店移入 `mall_interior`。

| 文件 | 处理 | 画面约束 |
| --- | --- | --- |
| `sunny-day.webp` | 新生成 | 晴天白昼，商场主体、运河与外街店铺保持固定锚点 |
| `sunny-dusk.webp` | 基于白昼构图编辑 | 17:00—20:00 的粉紫暮色，商场和路灯开始亮灯 |
| `sunny-night.webp` | 基于白昼构图编辑 | 20:00 后的真实夜景，窗光、路灯、车灯和湿润反光可见 |
| `cloudy-day.webp` | 新生成 | 阴天白昼，降低直射光但保持白天可读性 |
| `rain-day.webp` | 新生成 | 雨天白昼，湿地面与伞，不改变道路和店铺锚点 |
| `rain-dusk.webp` | 基于同一构图编辑 | 雨暮，暖色商场灯光与雨伞同时存在 |
| `rain-night.webp` | 基于同一构图编辑 | 雨夜，湿路反光和商场灯光，不使用纯黑压暗 |
