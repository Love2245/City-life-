2026-10-25追加柔和光影：`stillContactShadows.ts`根据已合成照片的深度生成接触阴影和短投影，强度0.30、接触半径0.34米；短投影强度0.13、距离不超过0.6米。投影方向由同一世界光向量随拍摄矩阵变换，切换四个方向时不会将阴影方向固定在屏幕上。阴影在1/3尺寸深度上计算，柔化后一次写入4K合成图；拖动、缩放、复位复用缓存，固定客房也使用其原始照片深度。不增加WebGL、模型、持续渲染或第二套4K图集。

2026-10-25重新从现有正式3D模型和材质离线生成。住宅背景原图为4096×3072，13套结构、20个地址，每套4个方向。默认按接近3D的实际大小显示局部画面，单指或鼠标拖动、双指或滚轮缩放、按钮缩放和复位都使用同一个视口坐标，设施定位随之更新。

每个可变图层附带无损PNG深度图，RG两个字节编码16位相机深度。运行时按逐像素深度合成，处理墙体、家具和道具交叉处的遮挡；家具移动时同时修正图像位置和深度。合成按条带进行以控制临时内存，配置不变时拖动和缩放只绘制缓存照片，不重新计算深度，也不创建3D模型。透明裁切图的像素尺寸按原始4K投影保留，没有先缩小再放大。

生成器：scripts/home-stills-baker.ts，深度工具：scripts/home-still-depth.ts，调用器：scripts/bake-home-stills.mjs。原始模型及贴图的来源、许可记录继续适用，本轮没有引入外部图片。

开启禁用热重载的1431服务，再运行HOME_BAKE_FULL=1的调用器可完整生成。调用器会保留每套结构JSON检查点；HOME_BAKE_IDS可限定结构列表。生成过程只在开发电脑使用WebGL，游戏的2D分支只使用图片和Canvas2D。
